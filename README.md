# Purpose-First Design

[한국어](README.md) | [English](README.en.md)

## 요약

제품 의미나 구현 계획의 방향이 실질적으로 열려 있을 때, 사용자와 도메인의 목적, 확정된 결정, 제약, 권한, 현재 근거와 관찰 가능한 성공에서 가장 작은 충분한 방향을 정합니다. 완료 전에 답변이 새로 만든 불필요한 범위와 약속을 줄이되 필요한 안전·운영 경계는 보존합니다.

## 빠른 시작

**설치**

```bash
npx skills add perhapsspy/purpose-fit-design
```

혹은 `skills/purpose-first-design` 폴더를 에이전트 스킬 디렉터리에 직접 복사합니다.

**바로 사용**

```text
$purpose-first-design 이 새 검색 기능에서 열려 있는 제품 방향을 목적과 확정된 제약에 맞춰 정해줘.

$purpose-first-design 이 기능의 임시 구현 방향을 정하고 그 판단을 바꿀 가장 작은 확인을 제시해줘.

$purpose-first-design 기존 흐름을 재사용할지 새 방향이 필요한지 판단해줘.
```

## 이런 때 사용

- 제품 의미나 구현 계획의 방향이 아직 중요한 선택으로 남아 있을 때
- 기존 구현을 재사용할지 새 방향이 필요한지 판단할 때
- 확정된 결정과 제약을 보존하며 임시 구현의 최소 방향을 정할 때
- 답변이 만든 불필요한 범위와 약속을 완료 전에 줄여야 할 때
